Descripción del Proyecto

Este sistema implementa técnicas avanzadas de aprendizaje automático para identificar comportamientos inusuales en transacciones bancarias, permitiendo detectar posibles fraudes sin necesidad de datos etiquetados.

  • Generación de datos sintéticos realistas
  • Análisis exploratorio automático
  • Reducción dimensional con PCA
  • Agrupamiento inteligente con KMeans
  • Visualización gráfica de anomalías
